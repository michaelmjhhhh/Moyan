# mdictcore provenance

This package is derived from `github.com/terasum/medict` at commit
`04f572a6258997125d6382486598e4c7d5018ea7`, with its original GPLv3 notices
preserved in the Go source files. Moyan is distributed under GPLv3.

The package is a temporary source-donor boundary. Parser hardening, bounded
allocation, checksum validation, and fixture coverage are required before
arbitrary user-supplied dictionaries are considered safe to open.
